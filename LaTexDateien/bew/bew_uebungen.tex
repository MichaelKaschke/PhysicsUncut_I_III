Sie ist ein weiteres Beispiel für komplexes, chaotisches Verhalten eines nichtlinearen Systems.
An diesem  System können gut allgemeine Charakteristika wie Bifurkationen\index{Bifurkationen}, das Einsetzen von Chaos oder der Ljapunow-Exponent\index{Ljapunow-Exponent} demonstriert werden.\\ 
\begin{enumerate}
  \item Stellen Sie die logistische Gleichung einer Population $X_{n+1}$ nach $n+1$ Jahren als Funktion der Population $X_{n}$ nach $n$ Jahren auf. 
	Berücksichtigen  Sie zwei Einflüsse:
\begin{itemize}
	\item Durch Fortpflanzung vermehrt sich die Population, im Folgejahr ist sie um einen Wachstumsfaktor $\alpha_{+}$ größer.
	\item Durch Verhungern/Jagen verringert sich die Population in Abhängigkeit von der Differenz zwischen ihrer aktuellen Größe und einer Maximalgröße $X_\text{max}$ mit der Proportionalitätskonstante $\beta$.
          Der Faktor, um den sich die Population vermindert, hat also die Gestalt $\alpha_{-}=\beta \,(X_\text{max}-X_n)$.
	\item Wenn man bei der Berechnung der Population im Folgejahr beide Prozesse berücksichtigt, erhält man: 
	\begin{align}
		X_{n+1} = \alpha_{+}\,\alpha_{-}\,X_{n} = \alpha_{+}\,X_n \: \beta \, (X_\text{max}-X_n) \,.\label{eq:bew_LogMap01}
	\end{align}
Um die Untersuchungen zu vereinfachen, wird die Populationsgröße $X_{n}$ als Bruchteil $x_n= X_n/X_\text{max}$ der Maximalgröße $X_\text{max}$ angegeben, man erhält die logistische Gleichung
	\begin{align}
		x_{n+1} = \gamma \,x_n\, \lk 1-\frac{x_n}{\kappa} \rk \,,\label{eq:bew_LogMap02}
	\end{align}
mit $\gamma= \alpha_{+}\, \beta \,X_\text{max}$ und $\kappa$ als der Kapazität der Populationsumgebung, die man \obda gleich eins setzen kann.
\end{itemize}
\item Berechnen Sie $x_n(n)$ für $\gamma = 2.75$, $\gamma = 3.25$ und $\gamma = 3.75$ und stellen Sie auch $x_{n+1}$ über $x_n$ dar.
  Beschreiben Sie das Verhalten.
\item Berechnen Sie das Bifurkationsdiagramm für die logistische Gleichung.
\item Berechnen Sie den Ljapunow-Exponenten für $\gamma = 2.75$ bis $\gamma = 3.75$.
\end{enumerate}
